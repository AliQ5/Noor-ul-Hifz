⚛ React 19 SPA

Dashboard & Quick Overview

The centralized hub of Noor-ul-Hifz gives teachers and administrators an instant bird's-eye view of active batches, registered students, total recorded sessions, and recent attendance entries.

  • ✓ KPI Metric Cards: Live counters for Registered Students, Total Logged Entries, Distinct Dates, and Active Batches.
  • ✓ Recent Attendance Sessions Table: Real-time overview of recorded dates, students logged, absent counts, takheer, and recitation issues.
  • ✓ Quick Action Shortcuts: Fast 1-click jumps to Import Excel Report, Student Directory, and Comparative Analytics.
  • ✓ Offline SQLite Indicator: Live file size monitoring and database connectivity badge in the sidebar footer.
👥 Class Management

Study Batches & Class Rosters

Manage multiple study circles, halaqahs, and academic levels within your madrasah. Group students into distinct classes with custom schedule descriptions.

  • ✓ Batch Segmentation: Create, edit, and categorize classes with custom schedule descriptions and student quotas.
  • ✓ Enrolled Student Rosters: Side-by-side roster inspection with student search, ID matching, and cumulative metrics.
  • ✓ 1-Click Excel Export: Export formatted batch rosters directly to Microsoft Excel for printouts and teacher markbooks.
  • ✓ Comparative Analytics Tab: Switch to batch performance charts, timeframe progressions, and Islamic grade rankings.
📈 Performance Profile

Collect Student Report & Filtering

Evaluate individual student performance with multi-faceted filtering. Inspect period tallies side-by-side with lifetime records, composite score ratings, and interactive streaks.

  • ✓ Multi-Dimensional Filters: Filter by All Records, Specific Date, Day of Week, Week Number (1–53), Month, Year, or custom Date Range.
  • ✓ Composite Scoring Index: Visual score badge with Islamic achievement tiers (Mumtaz ممتاز, Jayyid Jiddan, Jayyid, Maqbool).
  • ✓ 5 Category KPI Cards: Visual clearance rates for Attendance, Punctuality, Sabaq, Sabaqi, and Manzil.
  • ✓ 20-Day Interactive Activity Streak: Color-coded daily session timeline (Green, Amber, Red) with dates and day labels.
📋 Master Records

All Students Directory & Running Totals

A centralized, high-contrast table displaying every student in the local database with cumulative running totals across all monitored categories.

  • ✓ Zebra-Striped High-Contrast Table: Clean, responsive layout optimized for large student bodies and high legibility.
  • ✓ Running Condition Tallies: Instantly review lifetime absence, takheer, sabaq, sabaqi, manzil, and leave per student.
  • ✓ Batch / Class Tagging: Quickly identify which study circle each student belongs to, or filter unassigned students.
  • ✓ 1-Click Export & Safety Delete: One-click Excel spreadsheet export and safe record deletion with confirmation prompts.
📥 Flexible Logging

Excel Import & Manual Recitation Entry

Log attendance and recitation marks effortlessly through automated daily Excel sheet ingestion or manual keyboard entry.

View Screen:
  • ✓ Automated Sheet Parsing: Ingest teacher workbooks (.xlsx / .xlsm) with automatic ID/name mapping and date extraction.
  • ✓ Manual Recitation Logger: Instant student ID lookup, date picker, batch selector, and native Urdu condition checkboxes.
  • ✓ Clean Same-Day Upsert: Re-importing replaces daily marks cleanly without accumulating duplicate entries.
  • ✓ Configurable Mappings: Customize worksheet name (یومیہ رپورٹ), date cell (G1), and ID/Name columns in Settings.

The project

Built with care for real institute workflows.

Noor-ul-Hifz was created to replace scattered daily sheets with a consistent, practical record system. The goal isn't to make administration complicated. It's to make the information already being collected easier to keep, review, and use to inspire students.

نور الحفظ means "Light of Memorisation."
