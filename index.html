The project

Built with care for real institute workflows.

Noor-ul-Hifz was created to replace scattered daily sheets with a consistent, practical record system. The goal isn't to make administration complicated. It's to make the information already being collected easier to keep, review and use.

نور الحفظ means "Light of Memorisation."

Version 3.0 ★ Latest & Recommended Windows 10 / 11

Noor-ul-Hifz V3.0 (Setup)

Major upgrade introducing persistent local database storage, manual student entry without Excel, configurable categories, custom Excel sheet mapping, same-day upsert fixes, and one-click database backups.

Download V3.0 (ZIP) ↓ Noor-ul-Hifz-Setup-3.0.zip · Includes Installer

What's in Version 3.0:

✓
Persistent Database Storage

Stored safely in %LOCALAPPDATA%\Noor-ul-Hifz, permanently fixing data loss upon closing the one-file EXE.

✓
New Manual Entry Module

Record daily student status directly without needing an Excel sheet; loads existing students by ID.

✓
Corrected Same-Day Upsert

Re-importing or updating same-day records cleanly replaces flags instead of merging old marks.

✓
Configurable Custom Categories

Add new tracking categories, edit Urdu/English labels, and customize Excel row ranges in App Settings.

✓
Custom Excel Mapping

Customize the Excel worksheet name, report date cell, and ID / Name column ranges to match institute templates.

✓
1-Click Backup & Data Folder

Create timestamped database backups with one click and quickly access the local storage directory.

✓
Student & Record Deletion

Safely delete individual daily logs, remove all history for a student, or manage registered student records.

✓
Error Logging & Inno Setup

Built-in file logging (app.log) and professional Windows wizard installer with desktop/Start Menu shortcuts.
