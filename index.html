⚡ Core Workflow

Import Daily Excel Report

Directly load your institute's daily attendance workbook. Noor-ul-Hifz automatically parses ID and student names from columns [B,F] and [C,G], detects all five categories, and locks in records with zero retyping.

  • ✓ 5 Active Categories: Tracks Absent, Late, Sabaq, Sabqi, and Manzil automatically.
  • ✓ SQLite WAL Concurrency: High-speed write-ahead logging prevents file locking and database lag.
  • ✓ Overwrite & Future Date Protection: Same-day records cleanly replace flags rather than accumulating duplicate entries.
  • ✓ 100% Local & Private: Institute data stays on your computer with zero cloud exposure.
✎ Direct Logging

Manual Daily Entry Module

No Excel workbook today? Use the streamlined manual entry module to enter or adjust student records on the fly with instant student name loading and Urdu condition checkboxes.

  • ✓ Instant Student Lookup: Enter the Student ID and click "Load Student" to populate registered name instantly.
  • ✓ Urdu Checkboxes: Native labels for غیر حاضری، تاخیر، سبق کا ناغہ، سبقی کا ناغہ، منزل کا ناغہ.
  • ✓ Flexible Date Picker: Record today's attendance or backdate missed entries.
  • ✓ Fast Keyboard Navigation: Designed for rapid batch entry between prayer sessions.
👥 Master Records

All Students Directory & Totals

A centralized, high-contrast table displaying every student in the local database with cumulative running totals across all monitored categories.

  • ✓ Zebra-Striped Treeview: Polished, readable layout optimized for large student rosters.
  • ✓ Running Condition Tallies: Instantly review lifetime absence, late arrivals, and missed Sabaq/Manzil per student.
  • ✓ 1-Click Excel Export: Click "Export All to Excel" for office spreadsheets and printable academic reports.
  • ✓ Student Management: Safely delete or adjust selected student records with confirmation prompts.
🎨 Personalization

Appearance & 8 Accent Palettes

Noor-ul-Hifz V4 introduces full interface customization. Toggle between Dark Mode and Light Mode, choose from 8 curated accent color presets, or type any custom Hex color code.

The project

Built with care for real institute workflows.

Noor-ul-Hifz was created to replace scattered daily sheets with a consistent, practical record system. The goal isn't to make administration complicated. It's to make the information already being collected easier to keep, review and use.
